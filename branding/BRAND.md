# Btrfs Harbor Brand

## Name
Btrfs Harbor

## Mark
Lighthouse over immutable Btrfs snapshot layers

## Tagline
Snapshots in. Systems back.

## Personality
Calm, technical, dependable, precise.
Harbor is an operating-system utility, not a cloud SaaS dashboard.

## Visual language
- lighthouse signals a reliable recovery point;
- layered planes and water represent immutable Btrfs snapshots and safe arrival;
- generous negative space;
- strong small-size silhouette;
- no text inside the app icon.

## Palette
Core:
- Harbor Ink: #0B1622
- Deep Water: #14283A
- Harbor Teal: #58D6C5
- Foam: #EAF8F5
- Mist: #AFC5C7

Semantic:
- Healthy: #55D89A
- Attention: #F1B85B
- Critical: #EF6B73
- Information: #73B8FF

The interface must always pair semantic color with text/iconography.

## Typography
Prefer system UI fonts in-app for native integration.
README/logo lockup uses text rendered by HTML/Markdown rather than baking fonts into the SVG.

## Logo constraints
- mark remains readable at 16 px;
- monochrome variant must remain recognizable;
- no hairline strokes;
- no gradient dependency for recognition;
- dark and light surfaces;
- source SVG is canonical.

## README presentation
Centered logo.
Product name/tagline immediately below.
Language navigation: English · Français · 简体中文.
Then a concise "why" section before implementation details.

## UI feel
Information hierarchy:
1. protection state
2. next action
3. target health
4. chronology
5. filesystem detail

Simple mode uses outcome language.
Advanced mode exposes Btrfs terminology without euphemisms.

## Motion
Only meaningful:
- active send progress;
- status transition;
- route/panel transition.
Respect prefers-reduced-motion.
